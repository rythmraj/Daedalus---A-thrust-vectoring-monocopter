# Daedalus---A-thrust-vectoring-monocopter


**An experimental fully in-house monocopter developed by Aerolix Systems.**

Daedalus is an experimental aerial vehicle designed, developed, and tested from the ground up by **Aerolix Systems**.

Unlike conventional multirotors, the monocopter uses a fundamentally different flight architecture, combining a rotating airframe with **BLDC propulsion, custom electronics, sensors, and an in-house flight computer**.

## Main Objectives

The primary objectives of this project are:
* **Fly** — Achieve controlled and stable flight.
* **Hover** — Maintain a controlled hover for a useful period of time.
* **Safe Landing** — Return to the ground in a controlled and predictable manner.
* **Build Our Own Flight Computer** — Design and develop the flightcontrol electronics and software ourselves.
* **Build From Scratch** — Develop as much of the vehicle as possible in house rather than relying on ready made flightcontrol systems.

##  Key Technologies

### Propulsion
The monocopter uses **BLDC motors** as its primary propulsion system.
The propulsion subsystem includes:
* BLDC motor(s)
* Electronic Speed Controller(s)
* Propeller/rotor system
* LiPo battery
* Power distribution
* Motor control and throttle management

The propulsion system will be characterized through bench testing before being integrated into flight testing.

###  Flight Computer
One of the core objectives of this project is to develop our **own flight computer**.
The flight computer will be responsible for:
* Reading sensor data
* Estimating vehicle state
* Running control algorithms
* Controlling the propulsion system
* Monitoring system status
* Handling flightstate transitions
* Communicating telemetry
* Implementing safety and failsafe mechanisms

The exact hardware and software architecture will evolve throughout development.

## Servo-Based Thrust Vectoring & Control Flaps

A key part of the monocopter's flight-control system is a set of **servo actuated control flaps** used to influence the direction and magnitude of the aerodynamic forces generated by the vehicle.

### Objectives
The servo-based control system is intended to provide:
* **Attitude control** — influence the vehicle's orientation during flight.
* **Hover stabilization** — make continuous corrections to maintain a stable hover.
* **Rotational control** — control unwanted rotation and maintain the desired flight state.
* **Flight-path control** — provide a mechanism for correcting deviations from the desired trajectory.
* **Landing control** — allow the flight computer to make controlled corrections during descent and landing.

### Control Loop
The flight computer will continuously process sensor measurements and determine the required control response.
This creates a **closed-loop flight-control system**, where the vehicle continuously measures its response and adjusts the flaps accordingly.
The system will initially be tested with conservative flap deflections before progressively increasing the control authority as the vehicle's response is characterized.
